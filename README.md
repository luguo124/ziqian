# 字签官网

字签微信小程序的简约纸墨风格官网，包含真实模板画廊、在线试写、JPEG 图片下载及小程序码入口。

## 本地预览

无需安装依赖或构建：

```sh
python3 -m http.server 4180 --bind 127.0.0.1
```

打开 http://127.0.0.1:4180/ 。所有资源均使用相对路径，支持 GitHub Pages 的 `/ziqian/` 子路径。

## 验证

```sh
node scripts/check.mjs
node scripts/check-interactions.mjs
node --check app.js
```

检查模板、字体及印章数量，48 种模拟绘制状态，HTML ID、站内锚点和资源完整性。模拟画布检查不代表字体像素级或微信真机验证。

## 文件与能力

- `index.html`、`styles.css`、`app.js`：页面、响应式布局和交互。
- `mini-program.js`：从当前小程序的模板常量和 Canvas 绘制逻辑同步；官网仅省略落款前的破折号。
- `assets/miniprogram-code.jpg`：作者提供的小程序码原图，未裁剪或重绘。
- `assets/stationery.png`：AI 生成的静物配图，不作为小程序界面截图；模板预览由真实 Canvas 绘制。
- `assets/LICENSE.txt`：复用图标的许可说明。

网页提供 12 款模板、5 款自托管开源字体、横竖排、竖排列序、落款和 5 种印章选项（含无章）；轻体验限制为 40 字、最多 4 行，下载 720 × 900 JPEG。

首屏作品卡可拖动、点击、回车/空格或用交换按钮切换前后。触屏横向拖动可交换，纵向滚动交给浏览器，真机触屏仍需验证。

网页的五款字库为小薇宋、马善政、志莽行书、刘建毛草、龙藏，从 Google Fonts 官方仓库取得并压缩为 WOFF2。字体按需加载，提供状态、字形示例、超时与重试，加载期间不允许下载旧字形。来源与原文件 SHA256 见 `assets/fonts/sources.json`，各自 OFL 许可证随字体保留；不调用第三方字体 CDN。每款字体约 2.2–3.1 MiB，首次选择在弱网下会较慢，部分生僻字可能系统补字。小程序本身仍使用系统字库，本次未改动其代码。

暗色模式提高了正文、说明和占位文字的对比度，增强表单边界和选中状态，并增加相应对比度回归检查。

网页输入只在当前页面处理，刷新不保留，不写入小程序作品集。完整的草稿、作品集和系统相册保存流程请在小程序中使用；本地作品暂不支持云端同步。

## 发布与回滚

本仓库根目录为静态官网。GitHub Pages 继续沿用仓库现有发布设置，无需上传小程序工程或 Sites 私有项目配置。旧版 `css/`、`js/`、`images/` 保留，当前首页不再引用，历史版本仍可通过 Git 找回。

已在浏览器检查手机、平板、桌面布局，试写与实际图片下载。微信真机扫码、小程序发布状态、跨设备字体和 Lighthouse 完整审计仍需单独验证。
